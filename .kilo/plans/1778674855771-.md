# Plan: Convert Regular Search to Ask AI

## Overview
Remove the traditional keyword-based search feature. Convert the existing search box to "Ask AI" - the only search method will be AI-powered semantic search.

## Current State
- **Regular search**: `handleSearch()` in `app.js` → `/api/events/search` endpoint (SQL LIKE-based)
- **AI search**: `askAI()` function → `/api/ai/query` endpoint (Claude/OpenAI-based)
- **Search boxes**: Two instances (desktop `#searchInputDesktop`, mobile `#searchInputMobile`)

## Changes Required

### 1. Frontend (`src/index.tsx`)
- Remove the desktop search input from toolbar (lines 2278-2282)
- Remove the mobile search input (lines 2252-2258)
- Update the AI Assistant modal input to be the main "Ask AI" search
- Keep the AI Assistant modal as the primary search interface

### 2. Frontend (`public/static/app.js`)
- Remove `handleSearch()` function
- Remove the search event listeners for `data-search-input="events"`
- Remove search-related DOM elements

### 3. Backend (`src/index.tsx`)
- Remove the `/api/events/search` endpoint (lines 136-186)

## Implementation Order
1. Remove backend search endpoint
