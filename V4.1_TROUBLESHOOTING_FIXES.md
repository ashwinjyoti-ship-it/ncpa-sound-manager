### 5. ⚠️ IN PROGRESS: Export Change Tracking

**Problem:** Export doesn't show change tracking info

**How It Works:**
1. Click Export → System generates SHA-256 checksum
2. Checksum stored in localStorage: `lastExportChecksum`
3. Next export → Compares checksums
4. If different → Shows warning: "Data changed since last export"

**To Test Change Tracking:**
```javascript
// In browser console:
// 1. Check if tracking active:
localStorage.getItem('lastExportChecksum')

// 2. Force change detection:
localStorage.setItem('lastExportChecksum', 'old-checksum-value')

// 3. Export again → Should see change warning
```

**Manual Testing:**
1. Export CSV (first time)
2. Modify an event (change crew)
3. Export CSV (second time)
4. Browser console should show: "⚠️ X events have changed since last export"
